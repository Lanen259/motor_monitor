## Phase 1 — CMake 测试树打通（S2/S3 / A9）✅ 完成（2026-08-09）

做了什么（文档 ✅ 文件核验通过，但其声称"已可构建"不实——实测从未构建成功，按 §8 R-A 预案逐层修复）：

3. 8 个单元测试的 include 深度错误：位于 `tests/unit/<模块>/`（三层深）却写 `../../src/...`（只能到 `tests/src`）→ 全部改为 `../../../src/...`。
4. `src/parameter/CMakeLists.txt`：ParameterManager.h 内含 QWidget 子类 ParameterWidget → 补 `Qt5::Widgets` 链接。
5. `tests/CMakeLists.txt`：TestAutomationEngine 缺 `TestRunner.cpp`、`ReportGenerator.cpp` 源文件 → 补入；并为其注册 `TEST_DATA_DIR` 指向 JSON 夹具目录。
6. `tests/unit/automation/test_variable_scope.cpp`：QSignalSpy 捕获 `std::string` 信号参数 → 加 `Q_DECLARE_METATYPE(std::string)` + initTestCase 运行时注册。
7. 顶层 `CMakeLists.txt` 补 `enable_testing()`（原只在 tests/ 子目录，导致构建根目录 ctest 找不到测试）。
8. `scripts\gate.bat` 加防假阳性守卫：ctest 报 "No tests were found" 时强制退出码 1。

验证证据：
- gate.bat 步骤 1/3（qmake 全量构建）：编译+链接成功生成 `motor_antomation.exe`。
- gate.bat 步骤 2/3（CMake 测试构建）：13 个模块库 + 12 个测试可执行文件全部构建成功。
- 步骤 3/3（ctest，run11 终验）：`100% tests passed, 0 tests failed out of 12`，gate 退出码 0。
- 测试用例总覆盖：12 个可执行目标（单元 8 + 集成 2 + 基准 2），全部构建并运行。

修复的真实缺陷（此前从未跑过测试，暴露如下）：
- `MotorProtocol`：`sizeof(MotorDataPayload)` 实际 46 字节（4+10×4+2），旧断言 `>= 50` 在 Debug 下必崩 → 修正为 `== 46` 并修注释。
- `ExpressionEngine`：孤立 `&`/`|`/`=` 本应报错，但 tokenizer 用「塞 Eof 提前返回」实现，导致 `"2 & 3"` 被当成 `2` 求值 → 引入 `TokenType::Error`。
- `TestRunner`：析构里从主线程直接 `moveToThread` 无效且引擎仍绑定即将析构的工作线程 → 段错误；改为经工作线程的 BlockingQueuedConnection 迁回。`TestRunner(nullptr)` 用例空引擎未防护 → 加判空。无引擎失败结果同步发射导致 `QSignalSpy::wait()` 错过 → 改异步投递。
- `FlowGraph`：SetParameter 节点 label 被拼上 `" (Speed)"`、Wait 参数 `durationMs→ms` 翻译——测试期望过时 → 更新测试固化新契约（FlowRunner 执行键名）。
- `test_variable_scope`：`qvariant_cast<std::string>` 缺元类型注册 → `Q_DECLARE_METATYPE` + `qRegisterMetaType`。

验收：A9 达成（ctest 12/12 全绿）。
