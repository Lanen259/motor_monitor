## 关键设计决策

| 决策 | 结论 |
|------|------|
| 协议 | 直接使用 VOFA+ 协议（JustFloat），MCU 单向推送数据 |
| 通讯 | 串口为主，上位机命令通道 + MCU 数据推送通道分离 |
| 参数 | MCU 自行管理参数存储，上位机只负责读写显示 |
| 波形 | 自由运行无触发，15分钟环形缓冲，降采样显示 |
| 测试 | 表格配置（指令+延时+判断），完全自动化无人值守 |
| 脚本 | 不需要（表格配置满足需求） |
| 插件 | 不需要（内部工具） |
| 工程文件 | JSON 格式，启动后可在设置中导入 |
| 多设备 | 支持，不同设备分不同页面 |
| 日志 | 仅自动化测试时自动保存 |
